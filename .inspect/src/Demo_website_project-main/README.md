# Innovision 2027 — NSUT

A responsive, accessible showcase prototype for the NSUT event brief. It includes an original event mark, IST-aware live countdown, two-day schedule with track filters, and a registration flow with local confirmation handling.

## Judge demo

1. Open the page and use the countdown, hero CTA, and navigation links.
2. Switch between Day 01 / Day 02 and filter the programme by track.
3. Register with `2022UIC3457` to see the confirmation state.
4. Try an invalid roll number to see the accessible error hint.
5. Use Register another to replay the flow.

This is a student prototype for the Enactus R2 Tech Task and is not the official NSUT website. Event details are presented as a showcase concept.
